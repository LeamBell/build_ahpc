# Student Pro — Flutter Web

Готовая статическая сборка веб-приложения **Student Pro**, созданная с помощью Flutter и размещённая на GitHub Pages.

## Запустить приложение

Самый простой способ — открыть уже опубликованную версию: **[Запустить Student Pro](https://leambell.github.io/build_ahpc/)**.

Для локального запуска инструкции находятся в разделе [«Как запустить проект локально»](#как-запустить-проект-локально).

## О проекте

Репозиторий содержит готовую сборку Flutter-приложения:

- главная точка входа — `index.html`;
- скомпилированный код приложения — `main.dart.js`;
- загрузчик Flutter — `flutter_bootstrap.js`;
- PWA-манифест — `manifest.json`;
- значки и ресурсы приложения;
- библиотеки CanvasKit для рендеринга;
- сервисный работник для автономной работы и кеширования файлов.

## Как запустить проект локально

В ��епозитории находится готовая статическая сборка, поэтому для её запуска не нужны Flutter или Dart. Нужен любой локальный HTTP-сервер — открытие `index.html` напрямую через `file://` может не работать из-за ограничений браузера.

1. Склонируйте репозиторий и перейдите в его каталог:

   ```bash
   git clone https://github.com/LeamBell/build_ahpc.git
   cd build_ahpc
   ```

2. Запустите HTTP-сервер одним из способов.

   **Python 3:**

   ```bash
   python -m http.server 8080
   ```

   **Node.js:**

   ```bash
   npx serve .
   ```

3. Откройте указанный сервером адрес в браузере. Для Python это:

   ```text
   http://localhost:8080
   ```

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

> Команды `flutter run` и `flutter build web` нельзя выполнить непосредственно в этом репозитории: здесь нет исходников Flutter-приложения (`lib/` и `pubspec.yaml`), хранится только готовая веб-сборка.

## Развёртывание на GitHub Pages

Проект настроен для публикации с относительным базовым путём:

```text
/build_ahpc/
```

Для обновления опубликованной сборки:

1. В исходном проекте Flutter соберите приложение:

   ```bash
   flutter build web --release
   ```

2. Скопируйте содержимое каталога `build/web` в корень ветки `main` этого репозитория.

3. Зафиксируйте и отправьте изменения:

   ```bash
   git add .
   git commit -m "Update Flutter Web build"
   git push origin main
   ```

4. В настройках GitHub Pages выберите:

   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`

## Progressive Web App

Приложение поддерживает режим Progressive Web App:

- работает в автономном режиме;
- используется портретная ориентация;
- настроены тема и фоновый цвет;
- доступны значки для установки;
- сервисный работник кеширует файлы для повторного использования.

## Исходный код

В этом репозитории находится только готовая сборка Flutter Web. Исходные файлы приложения, включая `lib/` и `pubspec.yaml`, здесь отсутствуют.

Для запуска и изменения приложения как Flutter-проекта нужны его исходники. В каталоге исходного проекта установите зависимости и запустите приложение в Chrome:

```bash
flutter pub get
flutter run -d chrome
```

Чтобы собрать новую веб-версию:

```bash
flutter build web --release
```
